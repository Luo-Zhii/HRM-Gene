Gray-Box Testing Strategy

Black-box (HTTP via Supertest)

Real HTTP requests against localhost:3001 server. Validates HTTP status codes, response body shape, and data fields. No knowledge of internal implementation.

White-box (DB via TypeORM)

Direct PostgreSQL connection via TypeORM DataSource. Verifies data integrity after CRUD operations: row counts, column values, and entity relationships.

RBAC Authorization

Tests with 2 roles (Admin Director + User Staff). Validates 401 when unauthenticated, 403 when insufficient permissions. Covers every endpoint's auth behavior.

Hybrid (HTTP + DB Verify)

CRUD through HTTP API, then direct database read to verify data persisted correctly. Pattern: API call + DB read + assert + cleanup/rollback.

Cleanup & Restore

All create/update/delete tests clean up test data and restore original seed values. Ensures tests are repeatable and do not pollute the database.

Seed Data Integrity

Validates standard seed data: 40 employees, 5 departments, 4 positions, 12 payroll periods, 3 leave types, complete permissions matrix.
